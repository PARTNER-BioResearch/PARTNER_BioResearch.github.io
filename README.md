# P.A.R.T.N.E.R. BioResearch Landing Page

A polished one-page dynamic webpage for GitHub Pages.

## Files

- `index.html`
- `styles.css`
- `script.js`

## How to publish on GitHub Pages

1. Add these files to your GitHub Pages repository.
2. If this is your main site, place them in the root of `tpoe25.github.io`.
3. Commit and push.
4. Visit `https://tpoe25.github.io/`.

## Before publishing

Update these placeholders in `index.html`:

- Facebook button URL
- Email address
- Any official wording P.A.R.T.N.E.R. BioResearch wants used publicly
